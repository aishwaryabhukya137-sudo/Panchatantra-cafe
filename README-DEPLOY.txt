PANCHATANTRA CAFE — FINAL WEBSITE PACKAGE

INSTALL
1. Download and extract this ZIP.
2. Back up your current website/repository first.
3. Upload ALL files from this folder into the website ROOT (the same folder that contains index.html).
4. Replace existing files with the same names. Do not upload only index.html: styles.css, script.js and the image files must be uploaded too.
5. Keep CNAME, robots.txt, sitemap.xml and favicon.svg.
6. Commit/publish the updated files.
7. After publishing, open the website in a private/incognito tab or hard-refresh once to bypass old cached CSS/JavaScript.
