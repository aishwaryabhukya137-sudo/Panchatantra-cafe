PANCHATANTRA CAFE — UPDATED WEBSITE PACKAGE
=============================================

UPLOAD
1. Extract this ZIP.
2. Upload the CONTENTS of Panchatantra-cafe-main to the GitHub Pages repository root (not the enclosing folder).
3. Confirm GitHub Pages serves the apex domain and that the www hostname is added with a valid certificate before enabling the www redirect.
4. Test every route listed in sitemap.xml after deployment.
